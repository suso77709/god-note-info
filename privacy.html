기기에 저장하는 자료

개인 PDF, 노트, 필기, 메모와 설정은 앱의 기기 저장소에 저장합니다. 다른 앱에서 받은 PDF는 앱 내부 수신함에 복사하고, 노트 저장이 완료되면 임시 수신 파일을 지웁니다. 내보내기·갤러리 저장·클립보드·공유를 선택하면 사용자가 선택한 기기 위치나 앱으로 자료를 전달합니다.

Google Drive 동기화

사용자가 연결을 승인한 경우 노트·PDF·필기·메모와 동기화 수정 이력을 본인 Google Drive의 앱 전용 데이터 공간에 저장합니다. 같은 Google 계정으로 승인한 내 기기 사이에서 이 자료를 읽고 동기화합니다. 다른 Google Drive 문서 전체를 읽는 권한은 요청하지 않습니다.

계정의 고유 식별값과 이메일은 연결 계정 표시 및 다른 계정으로의 잘못된 업로드 방지를 위해 기기에 저장합니다. Google 로그인·권한·토큰 갱신에는 Google Play 서비스를 사용합니다. 앱 운영자의 원본 배포 서버나 안내 웹사이트에는 Google 비밀번호·접근 토큰·개인 필기 자료를 전송하지 않습니다.

산업 리포트 원본 서버

운영자의 컴퓨터 서버에서는 산업 리포트 채널의 원본 PDF만 내려받습니다. 이 서버로 개인 PDF·필기·메모를 업로드하지 않습니다. Google Drive 동기화는 이 원본 서버를 거치지 않습니다.

보관과 삭제

기기 자료는 앱 데이터 삭제 또는 앱 제거로 지울 수 있습니다. 노트 삭제는 동기화 기록을 통해 다른 기기에 반영합니다. 충돌 복구와 동기화를 위해 기존 수정 이력 및 PDF 원본은 Drive 앱 데이터 공간에 남을 수 있습니다. Drive의 앱 관리에서 GoD NoTe의 앱 데이터를 삭제하면 해당 공간의 자료를 지울 수 있습니다. 기기에 남아 있는 노트는 다시 동기화하면 업로드될 수 있으므로, 전체 삭제 시 각 기기의 연결과 기기 자료도 함께 정리하세요.

앱에서 연결 해제하면 이후 자동 동기화를 중지합니다. Google 계정의 연결된 앱 관리에서는 앱의 접근 승인을 철회할 수 있습니다. 연결 해제는 기존 기기 노트나 Drive 자료를 자동 삭제하지 않습니다.

서비스 제공업체

Google은 로그인·권한 및 Drive 저장을, Cloudflare는 원본 배포 서버 연결을, GitHub Pages는 이 안내 웹사이트 제공을 담당합니다. 이들 서비스는 네트워크 운영에 필요한 IP 주소·요청 시각·접속 정보 등을 자체 정책에 따라 처리할 수 있습니다. 이 안내 사이트에는 광고·별도 분석 추적 코드를 설치하지 않습니다.

Google 사용자 데이터 이용 제한

Google 사용자 데이터는 이 앱의 계정 확인과 사용자가 승인한 개인 노트 동기화에 사용합니다. 광고 타기팅, 판매, 다른 사용자의 노트 제공 또는 AI 모델 학습 용도로 사용하지 않습니다. GoD NoTe의 Google API 정보 사용 및 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
